# 单词手账 📓

每天贴好一页单词，词汇慢慢集齐。

一款移动端优先、单机无登录的校园手账风单词学习游戏。内置**三级 / 四级 / 六级**三套词库，任选其一或多个并行，按手账页收集、复习、盖章的方式学习，复习节奏由**艾宾浩斯遗忘曲线**安排。

## 题目顺序（2.0 起）

每一局固定分四段：

1. **① 英译中**：看单词选中文释义（4 选 1）
2. **② 中译英**：看中文释义选单词（4 选 1）
3. **③ 语境填空**：给一句挖空的真题/词典例句 + 中文翻译，从 4 个单词里选出合适的那一个（每题上限 10 道）
4. **④ 拼写**：字母贴纸（按顺序点击字母块）或自由拼写（键盘敲），在设置里切换；每次会话最多 **20 个**拼写词，按「今天学过的词 + 到期复习词」挑选

答错会在间隔 2~3 题后换一种题型重考（每个词每局最多出现 3 次，防无限膨胀）。

### 例句与语境题

- 每个词条自带 1 句真实例句 + 中文翻译（来自词书原生数据，不是编的）：四级 3691/3739（99%）、三级 3560/3665（97%）、六级 3411/3475（98%）有例句。
- 语境题只在「例句里能找到这个词」时出，挖空后保留原句，正确答案就是该词。
- 干扰项按词性分组挑（动词配动词、介词配介词），不会出现「a book \_\_\_\_ politics → potato」。

## 艾宾浩斯遗忘曲线

- 新学一个词（进入预览）即排第一次复习：**5 分钟**后。
- 每次答对往后推一档：5 分钟 → 30 分钟 → 12 小时 → 1 天 → 2 天 → 4 天 → 7 天 → 15 天（共 8 档）。
- 答错则回到第一档（5 分钟），并计入「遗忘次数」，错词池同步标记。
- 首页「🔔 艾宾浩斯复习」卡片显示实时到期词数，点一下就能复习这些词（最多 12 个一批）。

## 运行说明

### 环境要求

- Node.js ≥ 18
- pnpm（或 npm / yarn）

### 开发模式

```bash
cd cet4-handbook
pnpm install
pnpm run dev
```

浏览器打开终端提示的地址（默认 `http://localhost:5173`）。

### 生产构建

```bash
pnpm run build    # 类型检查 + 构建到 dist/
pnpm run preview  # 本地预览 dist/（默认 http://localhost:4173）
```

`dist/` 目录可直接部署到任意静态服务器，无后端依赖。

### 验收检查

```bash
node node_modules/.pnpm/esbuild@*/node_modules/esbuild/bin/esbuild scripts/validate.ts --bundle --platform=node --format=esm --outfile=scripts/validate.mjs
node scripts/validate.mjs
```

对三套词库分别校验：词条数量与唯一性、分页、单元结构、全词可搜索、题目生成规则、短词不出拼写题、Day 分布。输出全部 ✅ 即为通过。

## 数据文件位置

- 运行时数据目录：`public/data/`
  - `levels.json` —— 三个分级的元信息（词数 / 天数 / 页数 / 词库文件名）
  - `cet3_words.json` / `cet4_words.json` / `cet6_words.json` —— 三个词库
  - `game_config.json` —— 页面规模与游戏参数（1.0 遗留，仍保留）
- 构建时自动复制到 `dist/data/`，随应用一起部署。
- 启动时按 `levels.json` 校验词条数量与唯一性；校验失败会在加载页明确报错并停止，绝不生成假数据。
- 数据原文（`word` / `phonetic` / `partOfSpeech` / `meaning` / `rawDefinition`）一律原样展示，不做任何“纠正”。
- 重新生成词库：`python tools/build_levels.py`（源文件在 `tools/dict/`，百词斩词书数据）

## 添加到主屏幕（PWA）

- `manifest.webmanifest` + `sw.js`（离线缓存）+ `icons/`（192 / 512 / maskable / apple-touch）。
- 安卓 / 桌面 Chrome·Edge：安装提示会自动出现，设置页也有「📲 一键添加到主屏幕」按钮。

## 功能一览

- **游戏化进度**：答对 +100 分，连击 ≥3 后每连击 +20（封顶 +200），答对飘字反馈；累计总分对应手账段位（手账萌新 → 翻页新手 → 勤学贴纸控 → 手账老手 → 背词达人 → 单词大师 → 词汇收藏家）；连续学习天数、每日任务。
- **今日打卡**：完成一个单元即记一条打卡，首页显示最近 7 天（✓ + 单元数），结算页提示「今天第几个单元」。
- **每日一听**：每日一诵（18 篇轮换、逐句朗读、跟读模式、三档语速、关键词点读）+ 英语新闻（Hacker News 头条、标题朗读、原站链接、离线备用入口）。
- **主题色**：米白手账 / 薄荷绿 / 樱粉 / 夜航（深色），设置 → 外观切换，立即生效。
- **开始页**：三张词库卡（三级 / 四级 / 六级），点一下即切换；累计学习、已掌握、连续天数、总得分与段位。
- **今日手账**：日期、连续天数、当前进度、艾宾浩斯到期复习卡、今日计划（1~2 个新词页）、当前学习页、快捷入口。
- **手账目录**：Day 标签随词库天数变化；每个 Day 下按顺序解锁新词页、复习页、Day 测验；已完成页显示星星/金章；未开放页降对比度；测验不阻止进入下一 Day。
- **新词页**：先翻 10 张单词卡（可翻面看释义）→ 英译中 10 题 → 中译英 10 题 → 拼写（最多 20 个）；每页 1 次「翻小抄」。
- **复习页**：优先出艾宾浩斯到期词，不足时补最近三个新词页与最弱的词。
- **Day 测验**：混合词意与拼写，≥30% 历史错词；正确率 ≥90% 得金色 Day 印章；不阻止进入下一 Day。
- **折角错词页**：按最近错/错得多/按 Day 排序、翻卡复习、生成一组错词复习。
- **单词总表**：全量可搜（英文/中文）、状态/Day/首字母筛选、虚拟滚动。
- **词条详情**：原文定义 + 完整学习记录（含记忆阶段与下次复习时间）。
- **单词总表**：全量可搜（英文/中文）、状态/Day/首字母筛选、虚拟滚动、一键导出当前词库 CSV。
- **设置**：五组（学习 / 声音 / 外观 / 数据 / 关于）——词库切换、每日新词页、每页词数、拼写方式、音效/动画/语音朗读、主题色、添加到主屏幕、进度与词表导出导入、二次确认重置、反馈与关于。

## 已知限制

1. 语境题依赖例句：个别词没有例句（或例句里找不到该词）时，这一题不会出现，不影响其他题型。
2. 「三级」词库使用**高中英语大纲词汇**（3665 词），与三级（PRETCO A 级）3400 词大纲范围相当，但不是官方大纲逐条对照表——已在此如实说明。
3. 进度存浏览器 localStorage，按词库分开；清浏览器数据会丢（设置页可导出备份）。
4. 错词复习组（`W001`）与艾宾浩斯复习（`DUE`）为虚拟单元，不计入常规单元数。
5. 语音朗读依赖浏览器内置 `speechSynthesis`；没有英文语音包时走在线发音（需联网）。
6. **没有后端，做不到真正的推送**：「每日一诵」是内置内容按日期轮换；「英语新闻」是打开页面时实时取当日头条，不是定时推送。
7. 英语新闻源是 Hacker News（境外站点），国内网络不一定稳定；连不上会显示备用学习站入口。
8. 学习顺序按通用语料词频排，不是四六级真题词频（没有公开可用的真题词频数据）——所以第一页可能仍有个别你已认识的词。
